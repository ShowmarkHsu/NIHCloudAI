# NIHCloudAI v0.1.0 historical evidence

This directory preserves the governance, validation, and architecture records
that shipped with canonical commit `f48a7411786ecd7b6586ff26e33a446827d378b0`
and annotated tag `v0.1.0`.

These records remain part of the product lineage, but their validation results
apply only to the standalone v0.1.0 implementation. They do not satisfy the
v0.2.0 P2 controlled-manual-validation or P3 clinical/release evidence gates.
The current plan and release governance live at `docs/IMPLEMENTATION_PLAN.md`
and `docs/RELEASE_GOVERNANCE.md` after the integration migration.
